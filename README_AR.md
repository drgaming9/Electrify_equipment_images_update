# Electrify — Solar System Designer

موقع عربي ثابت يعمل على الهاتف والكمبيوتر، ولا يحتاج إلى قاعدة بيانات أو خادم برمجي.

## التشغيل على Windows

### الطريقة الأسرع
1. فك ضغط الملف.
2. شغّل `تشغيل_الموقع.bat`.
3. سيفتح الموقع على العنوان `http://localhost:8080`.

يجب أن يكون Python مثبتًا. يمكن أيضًا فتح المجلد في VS Code وتشغيل إضافة Live Server.

> فتح `index.html` مباشرة يسمح بمعظم الحسابات، لكن التثبيت كتطبيق والعمل دون إنترنت يحتاجان تشغيله عبر localhost أو رفعه إلى استضافة HTTPS.

## النشر على الإنترنت

ارفع محتويات المجلد كما هي إلى أي استضافة ملفات ثابتة، مثل GitHub Pages أو Netlify أو Cloudflare Pages أو استضافة cPanel. اجعل `index.html` في جذر الموقع.

## الميزات
- جدول أجهزة قابل للإضافة والحذف.
- الاستهلاك اليومي والحمل المتصل والمتزامن وذروة الإقلاع.
- شرح تفصيلي لسبب اختيار عدد الألواح ومعادلة الحساب.
- اقتراح قدرة الإنفرتر حسب الحمل المستمر وذروة الإقلاع.
- كتالوج مدمج لموديلات Deye أحادية وثلاثية الطور مع إمكانية اختيار موديل السوق أو إدخال موديل مخصص.
- الألواح والبطاريات ومنظم الشحن.
- تكوين السلاسل وفق مجال MPPT وحد الجهد والتيار وقدرة PV للموديل المختار.
- مقاطع كابلات وحمايات مبدئية وفق التيار وهبوط الجهد.
- تكلفة النظام حسب العملة والأسعار المدخلة.
- حفظ تلقائي وحفظ عدة مشاريع في المتصفح.
- تصدير واستيراد JSON.
- تقرير للطباعة أو الحفظ PDF من المتصفح.
- PWA قابل للتثبيت على الهاتف بعد رفعه إلى HTTPS.

## تنبيه
نتائج الكابلات والحمايات والتوصيل تصميم أولي فقط. التنفيذ النهائي يجب أن يراجعه مهندس كهرباء مرخّص وفق الكود المحلي، ظروف الموقع، طريقة التمديد، الحرارة، معدات المصنع ومتطلبات شركة الكهرباء.

## تسجيل الدخول

أضيف تسجيل Google والبريد الإلكتروني بواسطة Firebase Authentication. راجع ملف `إعداد_تسجيل_الدخول_Firebase.md` وأدخل بيانات مشروعك في `firebase-config.js` قبل النشر.


## تحديث الألواح
- اختيار محصور في لوحي Jinko 735 W و650 W المرفقين.
- السعر قابل للتعديل.
- عدد الألواح = `ceil(Pdc(STC) / Ppv)`.
- فحص MPPT لا يغيّر العدد تلقائيًا، بل يعرض حالة التوافق.
